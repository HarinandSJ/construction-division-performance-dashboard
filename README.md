# Construction Division - 2025-2026 Strategic Performance Dashboard

![Excel Dashboard Overview](Screenshot%202026-08-13%20190703.png)

## 📌 Business Overview & Executive Summary
This interactive Excel dashboard provides executive visibility into global construction division operations across financial performance, bid conversion efficiency, project pipeline status, and estimator effectiveness. 

Designed for strategic decision-making, the report allows leadership to analyze multi-billion dollar project portfolios, monitor regional cost distributions, and identify top-performing bidding personnel.

---

## 🛠️ Excel Architecture & Tools Used
* **Core Tool:** Microsoft Excel
* **Data Modeling & Calculations:** Excel Pivot Tables, Dynamic Named Ranges, Advanced Excel Formulas (`SUMIFS`, `COUNTIFS`, `GETPIVOTDATA`).
* **Visual Interactivity:** Connected Slicers (*Region*, *Estimator*, *Project Status*) driving multiple Pivot Charts simultaneously.
* **UI/UX Design:** Custom shape KPI cards, standardized color palette, drop shadows, and clean visual alignment.
